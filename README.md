- Установка зависимостей (нужен uv):
  `uv sync`

- Запуск:
  `uvicorn main:app --reload`

- Конфигурация:
 В данном приложении можно конфигурировать начальные условия генерации гексагонов (центр и радиус окружности) через .env

В реализации допущен ряд упрощений и допущений - если есть вопросы с радостью прокоментирую свой код!
